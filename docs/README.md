# Документация по проекту Geometric Lib

## 1. Общее описание решения 

Этот проект представляет собой библиотеку на Python для вычисления
площади и периметра различных геометрических фигур. 
Библиотека состоит из нескольких модулей:
* `circle.py` - вычисления для круга
* `square.py` - вычисления для квадрата
* `rectangle.py` - вычисления для прямоугольника
* `triangle.py` - вычисления для треугольника

## 2. Описание функций с примерами вызова 
### Модуль `circle.py`

**`area(r)`**
* **Описание:** Вычисляет площадь круга по заданному радиусу `r`.
* **Параметры:** `r` (int или float) — радиус круга.
* **Возвращаемое значение:** Площадь круга ($π * r^2$).
* **Пример вызова:**
    ```python
    import circle
    print(circle.area(5)) 
    # Вывод: 78.539...
    ```

**`perimeter(r)`**
* **Описание:** Вычисляет длину окружности (периметр) по заданному радиусу `r`.
* **Параметры:** `r` (int или float) — радиус круга.
* **Возвращаемое значение:** Длина окружности ($2 * π * r$).
* **Пример вызова:**
    ```python
    import circle
    print(circle.perimeter(5))
    # Вывод: 31.415...
    ```

### Модуль `square.py`

**`area(a)`**
* **Описание:** Вычисляет площадь квадрата по заданной длине стороны `a`.
* **Параметры:** `a` (int или float) — длина стороны квадрата.
* **Возвращаемое значение:** Площадь квадрата ($a^2$).
* **Пример вызова:**
    ```python
    import square
    print(square.area(7))
    # Вывод: 49
    ```

**`perimeter(a)`**
* **Описание:** Вычисляет периметр квадрата по заданной длине стороны `a`.
* **Параметры:** `a` (int или float) — длина стороны квадрата.
* **Возвращаемое значение:** Периметр квадрата ($4 * a$).
* **Пример вызова:**
    ```python
    import square
    print(square.perimeter(7))
    # Вывод: 28
    ```

### Модуль `rectangle.py`

**`area(a, b)`**
* **Описание:** Вычисляет площадь прямоугольника по двум сторонам.
* **Параметры:** `a` и `b` (int или float) — длины сторон прямоугольника.
* **Возвращаемое значение:** Площадь прямоугольника ($a * b$).
* **Пример вызова:**
    ```python
    import rectangle
    print(rectangle.area(5, 10))
    # Вывод: 50
    ```

**`perimeter(a, b)`**
* **Описание:** Вычисляет периметр прямоугольника по двум сторонам.
* **Параметры:** `a` и `b` (int или float) — длины сторон прямоугольника.
* **Возвращаемое значение:** Периметр прямоугольника ($2 * (a + b)$).
* **Пример вызова:**
    ```python
    import rectangle
    print(rectangle.perimeter(5, 10))
    # Вывод: 30
    ```

### Модуль `triangle.py`

**`area(a, h)`**
* **Описание:** Вычисляет площадь треугольника по длине основания `a` и высоте `h`.
* **Параметры:** `a` и `h` (int или float) — основание и высота.
* **Возвращаемое значение:** Площадь треугольника ($a * h / 2$).
* **Пример вызова:**
    ```python
    import triangle
    print(triangle.area(10, 5))
    # Вывод: 25.0
    ```

**`perimeter(a, b, c)`**
* **Описание:** Вычисляет периметр треугольника по длинам трех сторон.
* **Параметры:** `a`, `b`, `c` (int или float) — длины трех сторон.
* **Возвращаемое значение:** Периметр треугольника ($a + b + c$).
* **Пример вызова:**
    ```python
    import triangle
    print(triangle.perimeter(3, 4, 5))
    # Вывод: 12
    ```
